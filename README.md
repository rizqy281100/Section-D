## ✨ Komponen Halaman

1. **Navbar**: Logo AtapTropis, menu navigasi, tombol CTA, dan tombol menu untuk tampilan mobile.
2. **Hero Section**: Judul utama, deskripsi masalah rumah tropis, tombol aksi, dan foto asli arsitektur rumah modern.
3. **Product Benefits**: 6 card keunggulan atap iklim tropis.
4. **CTA Section**: Section ajakan untuk konsultasi gratis untuk mendapatkan leads.
5. **Dummy Contact Form**: Formulir pemesanan dengan field `required` dan pop-up `alert()` sukses saat pesan dikirim.
6. **Footer**: Informasi hak cipta dan nama website.
