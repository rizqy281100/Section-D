Section E — Dokumentasi Teknis Proyek Pendekatan Technical

BAB 2: Pendekatan Technical yang Digunakan

Pengembangan proyek memprioritaskan teknologi bawaan peramban (Vanilla Web Standard) tanpa beban pustaka eksternal pihak ketiga agar menghasilkan waktu muat secepat kilat (instant load).

2.1 Struktur Semantik HTML5

Alih-alih menggunakan elemen <div> secara berlebihan, proyek menggunakan tag semantik seperti <header>, <nav>, <section>, dan <footer>. Pendekatan ini meningkatkan keterbacaan kode bagi pengembang lain serta memudahkan mesin pencari (SEO) mengenali hierarki informasi.

2.2 Pemanfaatan Design Tokens (:root CSS)

Seluruh identitas desain dikelola terpusat pada variabel CSS (CSS Custom Properties). Palet warna hijau tua (#1b4332) melambangkan keteduhan iklim tropis, oranye hangat (#d97706) memberi aksen kontras sinar matahari pada tombol aksi, dan abu-abu lembut (#f8f9fa) menjaga kenyamanan mata pengunjung.

2.3 Tata Letak Responsif Modern (Flexbox & CSS Grid)

  • Flexbox: Mengatur susunan navigasi dan menyandingkan teks promosi dengan foto utama di desktop secara luwes.
  • CSS Grid: Mengatur 6 kartu keunggulan produk menjadi 3 kolom rapi di komputer, yang secara otomatis berubah menjadi 1 kolom vertikal saat diakses dari ponsel pintar.

2.4 Optimasi SEO On-Page & Open Graph

Di dalam tag <head> disematkan meta description, meta keywords relevan, dan tag Open Graph (og:title, og:description) sehingga tautan website menampilkan kartu pratinjau yang menarik saat dibagikan ke WhatsApp, LinkedIn, atau Twitter.

2.5 JavaScript Minimalis & Ramah Kinerja

Logika skrip ditulis di bawah 35 baris. Menggunakan metode event delegation sederhana untuk membuka/menutup menu di HP dan menangkap pengiriman formulir dengan event.preventDefault() guna menampilkan pesan konfirmasi tanpa memuat ulang halaman.

Section E — Dokumentasi Teknis Proyek Kendala & Peningkatan

BAB 3: Kendala yang Ditemukan & Solusinya

3.1 Menyeimbangkan Estetika dengan Kesederhanaan Kode

Kendala: Pembuatan awal menghasilkan CSS lebih dari 800 baris dengan animasi melayang yang rumit, sehingga dinilai kurang ramah bagi pelajar pemula.
Solusi: Melakukan perampingan (refactoring) menjadi 389 baris, mengganti animasi berat dengan transisi warna halus (transition: background-color 0.2s) yang tetap elegan namun mudah dipelajari.

3.2 Penanganan Gambar Eksternal agar Tidak Terdistorsi

Kendala: Gambar foto arsitektur dari Unsplash berisiko gepeng atau keluar batas kontainer saat layar diperkecil.
Solusi: Menggunakan kombinasi width: 100%; height: auto; display: block; border-radius: 8px; sehingga rasio landscape tetap presisi dan proporsional di segala ukuran layar.

3.3 Kerapian Navigasi pada Layar Sentuh Mobile

Kendala: Tautan navigasi desktop bertumpuk tidak beraturan di layar ponsel berukuran < 768px.
Solusi: Menggunakan media query @media (max-width: 768px) untuk menyembunyikan navigasi dan menampilkan tombol hamburger (☰). Tautan dibuat berukuran lega agar ramah sentuhan jari.

BAB 4: Rencana Peningkatan Jangka Panjang

  • Kalkulator Estimasi Atap Otomatis: Fitur interaktif di mana pengguna memasukkan luas bangunan (m²) dan langsung mendapatkan rekomendasi jumlah lembar atap beserta estimasi biayanya.
  • Integrasi Backend & Notifikasi WhatsApp Riil: Menghubungkan formulir kontak ke WhatsApp Business API atau email pengelola toko agar leads dapat langsung ditindaklanjuti.
  • Visualisasi 3D / Augmented Reality (AR): Fitur untuk mencoba warna atap secara langsung pada model rumah tropis secara 360 derajat.
  • Dukungan Multi-Bahasa & Mode Gelap: Pilihan Bahasa Inggris untuk wisatawan/investor villa dan Dark Mode untuk kenyamanan malam hari.
